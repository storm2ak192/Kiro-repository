# AnimeWitcher for Aniyomi

Port of the AnimeWitcher provider from Abodabodd/re-3arabi to the Aniyomi extensions API.

- Language: Arabic
- Source: https://animewitcher.com
- Supports Algolia catalog/search and Firestore episode/server metadata.
- Some playback hosts may require account verification or host-specific resolution support on the provider side.
